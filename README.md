# My Pi Extensions

A collection of self-contained Pi extensions.

## Extensions

- `bash-policy/` — policy checks for agent `bash` tool calls
- `pi-nvim-view/` — `/nvim` command for opening the latest completed assistant response in Neovim
- `pi-taskbar-info/` — custom footer with cwd, k8s context, and a context-usage bar graph
- `pi-tmux-notifications/` — tmux attention-state notifications for Pi activity

Each extension directory is intended to be installable with:

```bash
pi install /path/to/extension
```
